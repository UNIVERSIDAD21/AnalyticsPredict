# Resumen Ejecutivo 30s

## Endpoint
`GET /api/metricas/resumen-ejecutivo-compacto`

## Qué entrega
- GO/NO-GO
- score global
- semáforo global
- número de alertas críticas
- top 5 acciones priorizadas

## Uso
Ideal para check operativo rápido al inicio del día o antes de habilitar recomendaciones.
