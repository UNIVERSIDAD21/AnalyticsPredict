## Prioridad descartada por ahora

## Regla de gobierno
- Ninguna mejora pública debe maquillar diferencias reales de madurez entre módulos.
- Ninguna mejora freemium debe romper trazabilidad, legalidad o lectura correcta de métricas.
- Ninguna mejora de UX debe prometer funciones que la UI no pueda ejecutar de forma clara.
- Ninguna mejora de copy debe empujar el producto hacia narrativa de “ganar fácil”.
