# C4 — Inventario del flujo actual y fricciones

## Flujo actual levantado
1. Visitante
2. Registro/login
3. Aceptación legal
4. Onboarding
5. Dashboard
6. Suscripción/premium (feature-gate)

## Fricciones detectadas
- F1: Muro de acceso temprano para tráfico frío.
- F2: Valor inicial no siempre evidente antes de onboarding completo.
- F3: Riesgo de interpretación errónea del producto si el copy no se controla.
- F4: Distinción NBA/fútbol no siempre explícita en la capa inicial de expectativa.

## Decisión C4
No abrir features nuevas; refinar activación, capacidades y KPIs para mejorar entrada de valor sin cambiar estrategia comercial.
