# Revisión de Policy de Mercados

## Comando
```bash
cd /home/borlty/repos/AnalyticsPredict
make revision-politica
```

## Salida
`reports/policy_review/<timestamp>/REVISION_POLITICA.md`

## Incluye
- Resumen de mercados verde/amarillo/rojo.
- Mercados bloqueados actuales.
- Umbrales sugeridos automáticos por deporte.

## Uso recomendado
Correr semanalmente antes de ajustar policy gate en producción.
