# Contexto Estratégico y Objetivo del Proyecto

## Qué es realmente este sistema

AnalyticsPredict / DataAnalytics no debe pensarse solo como:

- recomendador de apuestas
- API de predicciones
- dashboard deportivo
- proyecto de machine learning aislado

Debe pensarse como un sistema que une cinco capas:

1. datos
2. analítica descriptiva
3. analítica diagnóstica
4. analítica predictiva
5. soporte a decisiones

## Dominios principales

Actualmente existen dos dominios grandes:

### 1. NBA / Baloncesto
Dominio más maduro, con valor operativo ya demostrado.

### 2. Football
Dominio en construcción, con avances en scraping e integración, pero aún sin la misma madurez operativa que NBA.

## Objetivo de esta fase

El objetivo NO es solo agregar features nuevas.

El objetivo es dejar el sistema listo para presentarse y evolucionarse como una plataforma seria de análisis de datos.

Eso implica fortalecer:

- coherencia estructural
- confiabilidad del dato
- trazabilidad
- explicabilidad
- consistencia analítica
- gobierno de modelos
- separación de dominios

## Resultado esperado

Al final de esta fase, el sistema debe poder defenderse como:

**Plataforma de Analítica de Datos Deportivos con trazabilidad, explicabilidad, monitoreo y capacidad de evolución.**
