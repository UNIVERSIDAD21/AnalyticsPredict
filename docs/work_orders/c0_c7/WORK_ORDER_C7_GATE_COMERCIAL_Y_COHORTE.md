# WORK_ORDER_C7_GATE_COMERCIAL_Y_COHORTE.md

## Objetivo
Validar AnalyticsPredict como negocio real mediante un gate comercial mínimo y una cohorte piloto controlada antes de escalar adquisición.

## Problemática
Sin un gate comercial formal, el proyecto puede confundir avance técnico con preparación real de negocio. C7 debe comprobar que cobro, uso premium, soporte básico y operación pueden sostenerse en una cohorte real.

## Tareas obligatorias
1. Ejecutar el flujo completo: registro → aceptación legal → onboarding → pago → uso premium → soporte básico → cancelación si aplica.
2. Validar ausencia de P0/P1 en la ruta comercial mínima.
3. Definir y operar cohorte piloto pequeña y medible.
4. Medir activación, conversión, incidencias y trazabilidad.
5. Emitir reporte formal de GO/NO-GO comercial.
6. Actualizar estado, changelog y evidencia final.

## Entregables
- Reporte de gate comercial.
- Evidencia E2E completa.
- Checklist de salida.
- Lista priorizada de defectos y decisión formal GO/NO-GO.

## Restricciones
- No escalar adquisición antes de tener decisión formal.
- No cerrar el bloque con percepciones; solo con evidencia.
- No ocultar incidencias críticas para forzar un GO artificial.

## Criterio de cierre
Se puede operar comercialmente una cohorte real sin romper pagos, confianza, trazabilidad ni gobierno operativo.
