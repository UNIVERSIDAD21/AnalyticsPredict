# WORK_ORDER_C5_PARIDAD_OPERATIVA_FUTBOL.md

## Objetivo
Llevar el módulo de fútbol a una condición operativa seria, aunque comercialmente siga etiquetado como beta/laboratorio hasta cumplir criterios de promoción.

## Problemática
Fútbol no debe eliminarse, pero tampoco maquillarse como equivalente comercial a NBA si todavía tiene huecos de contrato, mocks, esquema o trazabilidad.

## Tareas obligatorias
1. Cerrar endpoints huérfanos frontend/backend.
2. Eliminar mocks productivos.
3. Canonizar esquema y payloads de fútbol.
4. Llevar fútbol al mismo marco base de métricas, gates, trazabilidad y observabilidad.
5. Definir criterios objetivos de salida de laboratorio.
6. Actualizar documentación de estado, evidencia y changelog.

## Entregables
- Contrato canónico de fútbol.
- Dashboard sin mocks.
- Checklist de madurez de fútbol.
- Documento de criterios de promoción comercial.

## Restricciones
- No inflar madurez de fútbol por razones de marketing.
- No fusionar fútbol con NBA a nivel UX solo para ocultar diferencias de madurez.
- No cerrar el bloque sin evidencias y criterios objetivos.

## Criterio de cierre
Fútbol deja de ser frágil o ambiguo operativamente, aunque pueda seguir etiquetado como beta si así lo decide la estrategia comercial.
