# Estructura de Base de Datos - Sistema de Apuestas NBA

## 📊 Tablas Principales

### 1. **usuarios**
Gestión de usuarios del sistema.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | UUID | PK - Identificador único |
| `email` | VARCHAR(255) | Email único del usuario |
| `nombre` | VARCHAR(100) | Nombre del usuario |
| `password_hash` | VARCHAR(255) | Hash de contraseña |
| `rol` | VARCHAR(20) | 'usuario' o 'admin' |
| `activo` | BOOLEAN | Estado del usuario |
| `bankroll_inicial` | NUMERIC(10,2) | Bankroll de inicio |
| `bankroll_actual` | NUMERIC(10,2) | Bankroll actual |
| `perfil_riesgo_default` | VARCHAR(20) | CONSERVADOR/MEDIO/AGRESIVO |
| `config_sizing` | JSONB | Configuración de sizing |
| `preferencias` | JSONB | Preferencias del usuario |

**Índices:** email, activo

---

### 2. **temporadas**
Información de temporadas NBA.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | UUID | PK - Identificador único |
| `nombre` | VARCHAR(20) | Ej: "2024-25" |
| `anio_inicio` | INTEGER | Año de inicio |
| `anio_fin` | INTEGER | Año de fin (inicio + 1) |
| `fecha_inicio` | DATE | Fecha de inicio |
| `fecha_fin` | DATE | Fecha de fin |
| `activa` | BOOLEAN | Temporada activa |

**Constraints:** `anio_fin = anio_inicio + 1`

---

### 3. **equipos**
Catálogo de equipos NBA.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | UUID | PK - Identificador único |
| `nombre` | VARCHAR(100) | Nombre completo (único) |
| `nombre_corto` | VARCHAR(50) | Nombre corto |
| `abreviatura` | VARCHAR(3) | Abreviatura única |
| `conferencia` | VARCHAR(10) | Este/Oeste |
| `division` | VARCHAR(20) | División del equipo |
| `ciudad` | VARCHAR(100) | Ciudad |
| `activo` | BOOLEAN | Equipo activo |

**Índices:** nombre, abreviatura, conferencia

---

### 4. **partidos**
Registro de partidos jugados.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | UUID | PK - Identificador único |
| `temporada_id` | UUID | FK a temporadas |
| `fecha_partido` | DATE | Fecha del partido |
| `tipo_partido` | VARCHAR(10) | PRE/REG/POST |
| `equipo_local_id` | UUID | FK a equipos |
| `equipo_visitante_id` | UUID | FK a equipos |
| `local_q1/q2/q3/q4` | INTEGER | Puntos por cuarto local |
| `visitante_q1/q2/q3/q4` | INTEGER | Puntos por cuarto visitante |
| `local_ot` | INTEGER | Puntos overtime local |
| `visitante_ot` | INTEGER | Puntos overtime visitante |
| `local_total` | INTEGER | Total puntos local |
| `visitante_total` | INTEGER | Total puntos visitante |
| `ganador_id` | UUID | FK al equipo ganador |
| `diferencia_puntos` | INTEGER | Diferencia final |
| `hubo_overtime` | BOOLEAN | Si hubo overtime |
| `espn_game_id` | TEXT | ID de ESPN |
| `source` | TEXT | Fuente de datos |
| `source_game_id` | TEXT | ID de la fuente |

**Constraints únicos:** 
- `(temporada_id, fecha_partido, tipo_partido, equipo_local_id, equipo_visitante_id)`
- `(source, source_game_id)`

**Checks importantes:**
- Equipos diferentes
- Suma de cuartos = total
- Todos los valores ≥ 0

**Índices:** fecha, equipos, temporada, tipo

---

### 5. **estadisticas_equipos**
Estadísticas agregadas por equipo y temporada.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | UUID | PK - Identificador único |
| `equipo_id` | UUID | FK a equipos |
| `temporada_id` | UUID | FK a temporadas |
| `victorias/derrotas` | INTEGER | Record general |
| `victorias_local/visitante` | INTEGER | Record por localía |
| `ppg_q1/q2/q3/q4/total` | NUMERIC(5,2) | Puntos por juego |
| `opp_q1/q2/q3/q4/total` | NUMERIC(5,2) | Puntos oponente |
| `over_pct_q1/q2/q3/q4/total` | NUMERIC(5,4) | % de overs |
| `partidos_jugados` | INTEGER | Total de partidos |

**Constraint único:** `(equipo_id, temporada_id)`

Calibradores de probabilidades.

| Campo | Tipo | Descripción |

## 📊 Vistas Principales

### **vista_analisis_apuestas**
Análisis completo de apuestas con métricas calculadas.

**Incluye:**
- Información básica de apuesta
- Métricas de devig (vig %, edge)
- Scoring y clasificación
- Kelly y sizing
- ROI y resultados
- Flags de advertencia

### **vista_predicciones_para_calibracion**
Predicciones resueltas listas para calibración.

**Incluye:**
- Datos completos de predicción
- Bins de probabilidad
- Nombres de equipos y temporada
- Probabilidad efectiva (calibrada o raw)

### **vista_predicciones_pendientes**
Predicciones sin resolver con estado del partido.

### **vista_resumen_calibracion**
Métricas agregadas de calibración por mercado y origen.

**Incluye:**
- Promedios de probabilidad
- Frecuencia real
- Brier scores
- Sesgo y sharpness
- Rango de fechas

### **vista_resumen_apuestas**
Resumen estadístico por usuario.

**Incluye:**
- Total de apuestas
- Win rate
- ROI
- Ganancia total
- Desglose por resultado

### **vista_alertas_activas**
Alertas no resueltas ordenadas por severidad.

### **vista_ultimos_partidos**
Últimos partidos jugados con resultados.

## 🔗 Relaciones Principales

```
usuarios (1) ──→ (N) apuestas
temporadas (1) ──→ (N) partidos
temporadas (1) ──→ (N) estadisticas_equipos
equipos (1) ──→ (N) partidos (local/visitante/ganador)
equipos (1) ──→ (N) estadisticas_equipos
partidos (1) ──→ (N) apuestas
partidos (1) ──→ (N) predicciones_registradas
modelo_versiones (1) ──→ (N) predicciones_registradas
modelo_versiones (1) ──→ (N) metricas_calibracion
modelo_versiones (1) ──→ (N) alertas_calibracion
calibradores (1) ──→ (N) predicciones_registradas
```

## 📝 Notas Importantes

### Timestamps
Todas las tablas principales tienen:
- `creado_en`: TIMESTAMP WITH TIME ZONE DEFAULT now()
- `actualizado_en`: TIMESTAMP WITH TIME ZONE DEFAULT now()

### UUIDs
La mayoría de PKs son UUID generados con `uuid_generate_v4()`

### Checks Importantes
- Cuotas > 1.0
- Probabilidades entre 0 y 1
- Stakes > 0
- Valores no negativos en puntos y estadísticas
- Enums para estados y tipos

### Mercados Disponibles
Q1, Q2, Q3, Q4, COMPLETO, GLOBAL

### Orígenes de Datos
- API_USUARIO: Predicciones de API
- BACKTEST_BATCH: Backtest en lote
- BACKTEST_SINTETICO: Backtest sintético
- MIXTO: Combinación de orígenes
